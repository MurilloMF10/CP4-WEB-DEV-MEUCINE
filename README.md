## Sobre o projeto

O **Meu Cine** é um projeto acadêmico desenvolvido para facilitar a descoberta e a organização de filmes e séries. A plataforma permite pesquisar títulos, consultar informações importantes e salvar conteúdos em uma lista pessoal para assistir depois.

O projeto foi pensado a partir do fim do TV Time. Em vez de recriar toda a antiga aplicação, nosso grupo escolheu focar em uma experiência simples para quem quer encontrar algo para assistir, guardar recomendações e verificar onde procurar cada título.

## Problema

Quem consome streaming costuma lidar com muitas opções, recomendações que acabam esquecidas e a necessidade de pesquisar informações em vários lugares. Sem uma lista pessoal, é fácil perder um filme ou uma série que parecia interessante.

## Nossa solução

O Meu Cine reúne em uma única plataforma:

- Catálogo de filmes e séries para descoberta de conteúdos.
- Busca por título e filtro por gênero.
- Página de detalhes com sinopse, nota, ano e categorias.
- Consulta de serviços de streaming disponíveis no Brasil.
- Área **Minha Lista** para salvar e remover títulos.
- Dados locais de demonstração quando a API estiver indisponível.

## Funcionalidades

| Funcionalidade | Descrição |
| Catálogo | Exibe seções organizadas de filmes e séries. |
| Busca | Localiza conteúdos a partir do título informado. |
| Categorias | Permite explorar outros títulos do mesmo gênero. |
| Detalhes | Apresenta informações como capa, sinopse, ano, nota e tipo. |
| Onde assistir | Consulta serviços de assinatura, aluguel ou compra no Brasil. |
| Minha Lista | Salva títulos no navegador e mantém a lista após atualizar a página. |
| Modo offline | Usa dados locais e exibe um aviso caso a API não esteja disponível. |

## Tecnologias

| Tecnologia | Uso no projeto |
| React | Construção dos componentes e atualização da interface. |
| Vite | Ambiente de desenvolvimento e geração da versão de produção. |
| React Router | Navegação entre Catálogo, Detalhes e Minha Lista. |
| React Icons | Ícones da marca, busca e navegação. |
| JavaScript, HTML e CSS | Estrutura, comportamento e estilo da plataforma. |
| API do TMDB | Dados de filmes, séries, avaliações, sinopses e streaming. |
| Armazenamento local | Persistência de Minha Lista no navegador. |
